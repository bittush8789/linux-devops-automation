# Linux DevOps Automation

A curated collection of Bash shell scripts and automation utilities to simplify common **Linux system administration** and **DevOps tasks**.

This repository helps automate repetitive tasks like service management, backups, log rotation, monitoring, package installation, and more — saving time and reducing human error.

---

## 🚀 Features

✔ Automate user and group management  
✔ Service start/stop/restart automation  
✔ System monitoring & alerts  
✔ Backup and cleanup scripts  
✔ Installation & configuration helpers  
✔ Structured folders for Apache, Docker, Jenkins, Terraform, Nginx, Minikube, JDK, and more  

- **Apache/** – Scripts for Apache installation & monitoring  
- **Docker/** – Docker related automation scripts  
- **JDK/** – Java JDK installation & configuration  
- **Jenkins/** – Setup helpers & maintenance scripts  
- **Minikube/** – Kubernetes local environment automation  
- **Nginx/** – Nginx setup & management scripts  
- **Python File Sorter/** – Python utility for file sorting  
- **Terraform/** – Scripts to assist Terraform automation
